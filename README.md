# Ɛpsilon Notes

This is where I keep the things I'm learning — and the things I want to remember later.

It's a personal notebook: half-formed ideas, explainers I wrote for myself, and write-ups of
problems I've already solved so I never have to solve them twice. Nothing here is finished or
polished on purpose; a note is finished the moment it helps me think.

Notes are plain Markdown files and are published to **<https://3p5ilon.github.io/notes>**.

## Built on Quartz

The site is generated by [Quartz v5](https://quartz.jzhao.xyz/) — a fast, hackable static site
generator for a digital garden. All the machinery lives in [`quartz/`](./quartz), and everything
site-specific (title, theme, colors, which plugins are on) lives in
[`quartz.config.yaml`](./quartz.config.yaml).

## Writing

```bash
npx quartz create          # new note, opens in your editor
npx quartz build --serve   # live preview at http://localhost:8080
npx quartz sync            # commit + push; the site redeploys on its own
```

## Layout

| Path                 | What's in it                                   |
| -------------------- | ---------------------------------------------- |
| `content/`           | The notes. This is the part that matters.      |
| `quartz.config.yaml` | Title, theme, plugins, footer links.           |
| `quartz/`            | The Quartz engine — rarely needs touching.     |
| `public/`            | Build output. Generated, don't edit or commit. |

Anything under `private/`, `templates/`, or `.obsidian/` is ignored by the build, which is handy
for scratch notes and reusable snippets you don't want published.
