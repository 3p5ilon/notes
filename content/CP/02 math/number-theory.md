## Even & Odd

- **Even:** `2k`
- **Odd:** `2k + 1`
- every odd no >= 3 can be written as `3 + 2 ... n`

  bcz `2k + 1 → 1 + 2 + 2 ... n → 3 + 2 ... n
`

- Check even: `x % 2 == 0`
- Check odd: `x % 2 == 1`

### Sum

- Sum of first `n` odd numbers:
  `1 + 3 + 5 + ... + (2n-1) = n²`
- Sum of first `n` even numbers:
  `2 + 4 + 6 + ... + 2n = n(n+1)`
